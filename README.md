# Мод: замена текстур существ — Heroes of Might and Magic V 3.1

Готовый мод: **`zz_CreatureTextures_H5_3.1.pak`** (32 текстуры, ~3 МБ)

## Установка

1. Найдите папку игры Heroes of Might and Magic V — Tribes of the East
   («Повелители Орды», версия 3.1), внутри неё — папку **`data`**
   (там уже лежат `data.pak`, `text.pak` и т.п.).
2. Скопируйте туда файл **`zz_CreatureTextures_H5_3.1.pak`**.
3. Запустите игру — новые текстуры подхватятся автоматически,
   ничего настраивать не нужно. Префикс `zz_` в имени важен: игра читает
   .pak-файлы по алфавиту, и этот архив должен читаться **после** `data.pak`,
   чтобы его текстуры перекрывали оригинальные.

**Удаление мода** — просто удалите этот .pak из папки `data`.

> ⚠️ Сетевая игра: у всех игроков должен стоять одинаковый набор .pak-файлов,
> иначе возможны рассинхронизация/вылеты. Для одиночной игры всё в порядке.

## Что заменяется

Каждая PNG из папки `Текстуры` сопоставлена с оригинальной текстурой игры
по UV-раскладке атласа из `data.pak` (версия 3.1) и перекодирована в DDS
в исходном разрешении, формате DXT1/DXT3 и с исходным числом mip-уровней.
Заменяются и основная (512 px), и LOD-версия (256 px) каждой текстуры —
иначе на дальних планах существо выглядело бы по-старому.

| Существо | Текстуры |
|---|---|
| Крестьянин (Оплот) | основная |
| Фея / Pixie (Лесной союз) | основная + _add (волосы) |
| Дриада / Spirit (Лесной союз) | основная + _add (волосы) |
| Эльфийский лучник / Wood Elf | основная |
| Высший эльф / High Elf | основная |
| Друид (Лесной союз) | основная + _add (плащ/посох) |
| Демилич (Некрополис) | основная |
| Владыка личей / Lich Master (Некрополис, альт. апгрейд) | основная + _add |
| Защитник / Defender (Крепость) | тело + металл |
| Копейщик / Spear Fighter (Крепость) | тело + металл |
| Балор / Balor (Инферно) | основная + меч |

Итого: 18 PNG → 32 игровых .dds (основные + LOD).

## Нюансы

- **Альфа-канал** в ваших PNG отсутствует, поэтому в мод он перенесён из
  оригинальных DDS. Это важно для `_add`-текстур, крыльев и рваных краёв
  плащей: без оригинальной альфы они стали бы непрозрачными прямоугольниками.
- В папке лежат **два почти одинаковых варианта** текстуры волос Феи
  (`...1792354305719...` и `...1792354571328...`). В мод взят первый.
  Хотите второй — поменяйте имя в `build_mod.py` (комментарий в `MAPPING`)
  и пересоберите мод.
- Разрешение в игре останется родным (512/256): движок HoMM5 берёт размеры
  из описания текстуры, поэтому «апскейл» до 1254 px на модели всё равно
  ужался бы. Выигрыш мода — в самой перерисованной картинке.

## Пересборка

```bash
pip install pillow numpy
python3 build_mod.py            # сам найдёт data.pak / data.z01..data.zip рядом
# или явно:
python3 build_mod.py /путь/к/data.pak
```

Скрипт `build_mod.py` достаёт оригинальные DDS из `data.pak` (из многотомного
`data.z01…data.z18 + data.zip`), перекодирует PNG в DXT и собирает
`zz_CreatureTextures_H5_3.1.pak`. Полное соответствие «PNG → игровой файл» —
в словаре `MAPPING` в начале скрипта.
